What is an API call (answer in your own words)?


API (or application programming interface) is a protocol to connect an individual with some sort of software. Basically, it is a request made to another software to be utilized for a certain functionality the software we are requesting possess.

What is an example we discussed to create an API call locally?


An example we discussed to create a API call locally in the video is FastAPI. We downloaded FastAPI into a virtual environment and afterwards ran the code locally using a python script we originally defined. As a result, we were able to access the API we defined in our own browser. However this would not work for other people as it was created for nobody besides those in our network to access.

What is an example we discussed to create an API call on the cloud? 


An example of creating an API call on the cloud discussed in the video was shown through AWS Gateway. The difference between API calls made using AWS Gateway compared to FastAPI is that now the API can be accessed anywhere and by anyone outside the network.

What is the difference between FastAPI and creating API from AWS Gateway?


The main difference between using FastAPI and creating API from AWS Gateway is that while users could access FastAPI if they are on the same network it was created in, this makes it very difficult for those not on said network to access the call. However, while it may take more time to create an API on a cloud, it allows users from a variety of places and different networks to be able to use the API Call. Furthermore, while FastAPI and local clouds may be easier in the short term to create, API calls created in a cloud do take a longer time to create such as setting up lambda functions, setting up a trigger through API Gateway, and testing the API to see if it actually works. Basically, FastApi’s are faster to set up but less accessible while AWS Gateway’s APIs take more time to set up but in the long run are more accessible.

In your own words after watching the video, what are the main steps to create an API call on AWS Gateway?

The main steps for setting up an API call on an AWS Gateway is first setting up the lambda function, setting up the trigger for the lambda, testing to see if the function is working, and then deploying the API for wideuse.
